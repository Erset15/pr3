# Классификация самолётов: военный или гражданский

Сравнение двух визуально-языковых моделей (VLM) на Hugging Face для бинарной классификации авиационных фотографий по принципу zero-shot.

## Постановка задачи

- Задача: по фотографии определить, является ли самолёт военным или гражданским.
- Инструмент: провайдеры LLM/VLM на Hugging Face.
- Требования:
  - Сравнить метрики двух выбранных моделей.
  - Составить выборку с нетривиальными случаями (бизнес-джеты, самолёты ДРЛО, необычные ракурсы).
  - Не использовать слишком большую выборку (около 30 самолётов достаточно) из-за ограничений на бесплатные запросы.

## Выбранные модели

| Модель | Назначение |
|---|---|
| openai/clip-vit-base-patch32 | Аннотатор (автоматическая разметка) + модель №1 для сравнения |
| google/siglip-base-patch16-224 | Модель №2 для сравнения |

Обе модели поддерживают zero-shot image classification: им передаётся изображение и список текстовых меток, модель возвращает вероятности для каждой метки.

## Установка

```bash
pip install transformers torch pillow scikit-learn sentencepiece protobuf
```

Или через requirements.txt:

```bash
pip install -r requirements.txt
```

Примечание для Windows / медленного интернета: если скачивание моделей с Hugging Face зависает, задайте зеркало в той же сессии терминала:

```powershell
$env:HF_ENDPOINT="https://hf-mirror.com"
```

Также рекомендуется отключить новый загрузчик Xet, если он вызывает проблемы:

```python
import os
os.environ["HF_HUB_DISABLE_XET"] = "1"
```

## Запуск

Скрипт работает в два шага.

### Шаг 1. Автоматическая разметка датасета

При первом запуске (когда dataset/labels_auto.csv ещё не существует) скрипт:

1. Находит все изображения в dataset/ (.jpg, .jpeg, .png).
2. Прогоняет их через модель-аннотатор openai/clip-vit-base-patch32.
3. Сохраняет результат в dataset/labels_auto.csv с колонками filename,label,confidence.
4. Фото с уверенностью ниже порога (CONFIDENCE_THRESHOLD = 0.60) помечает как uncertain.

```bash
python main.py
```

Пример вывода:

```

Найдено 30 изображений. Загружаем модель-аннотатор: openai/clip-vit-base-patch32
Автоматическая разметка...
  Обработано 8/30
  ...
  0af52a69...jpg   -> civilian   (уверенность 0.912)
  2.jpg            -> military   (уверенность 0.874)
  i (1).jpg        -> uncertain  (уверенность 0.512)

Разметка сохранена в dataset/labels_auto.csv
Итого: военных=12, гражданских=14, спорных=4
```

## Метрики

| Метрика | CLIP | SigLIP |
|---|---|---|
| Accuracy | 1.0000 | заполняется после запуска |
| Precision | 1.0000 | заполняется после запуска |
| Recall | 1.0000 | заполняется после запуска |
| F1-score | 1.0000 | заполняется после запуска |

### Интерпретация

- CLIP = 1.0 — ожидаемый результат, поскольку истина в labels_auto.csv была создана самим CLIP. Это проверка согласованности, а не реального качества модели.
- SigLIP выступает как независимая проверка. Расхождения с разметкой CLIP указывают на спорные или нетривиальные кадры (бизнес-джеты, самолёты ДРЛО, необычные ракурсы). Такие файлы стоит перепроверить вручную.

## Нетривиальные случаи в выборке

В датасет включены изображения, которые сложно классифицировать однозначно:

- бизнес-джеты (визуально близки к военным);
- самолёты ДРЛО и транспортники;
- снимки под необычным углом (нижний ракурс, силуэт);
- изображения с нестандартной ливреей.

Именно на них чаще всего расходятся предсказания CLIP и SigLIP.

## Возможные проблемы и решения

| Проблема | Решение |
|---|---|
| SiglipTokenizer requires the SentencePiece library | pip install sentencepiece |
| SiglipTokenizer requires the protobuf library | pip install protobuf |
| Скачивание модели зависает | $env:HF_ENDPOINT="https://hf-mirror.com" + os.environ["HF_HUB_DISABLE_XET"] = "1" |
| git не распознан | Установить Git и выбрать опцию Git from the command line and also from 3rd-party software |
| Датасет пуст | Проверить, что в dataset/ есть изображения и labels_auto.csv содержит строки military/civilian |

## Результаты

| Метрика | CLIP | SigLIP |
|---|---|---|
| Accuracy | 1.0000 | 0.9615 |
| Precision | 1.0000 | 0.9231 |
| Recall | 1.0000 | 1.0000 |
| F1-score | 1.0000 | 0.9600 |

### Интерпретация результатов

- CLIP показал Accuracy = 1.0, потому что истина в labels_auto.csv была создана самим CLIP. Это проверка согласованности разметки, а не реального качества модели.
- SigLIP, как независимая модель, показал Accuracy = 0.9615 и F1 = 0.9600. Recall = 1.0 означает, что ни один военный самолёт не был пропущен. Precision = 0.9231 говорит об одном ложном срабатывании.
- Единственная ошибка SigLIP — файл i.jpg: модель приняла гражданский самолёт за военный. Это и есть нетривиальный случай, который стоит перепроверить вручную в labels_auto.csv. Если метка в CSV верна, то ошибка относится к SigLIP; если нет — это ошибка автоматической разметки CLIP.
- В целом обе модели хорошо справляются с задачей zero-shot классификации на выборке из 26 изображений. SigLIP немного уступает CLIP по Precision, но не пропускает военные самолёты, что критично для практических задач распознавания военной техники.
